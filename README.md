# 📊 X (Twitter) Data Crawling & Sentiment Analysis Pipeline

Sistem otomasi ekstraksi data dari platform X (Twitter) dan analisis sentimen opini publik yang dirancang untuk mendukung riset akademik serta analisis persepsi publik.

## 📌 Fitur Utama
* **Automated Data Extraction:** Ekstraksi postingan dan interaksi berdasarkan kata kunci (*keyword*) atau tagar tertentu.
* **Text Preprocessing:** Pembersihan teks otomatis (*cleansing, case folding, filtering, normalization*).
* **Sentiment Classification:** Pengelompokan opini publik secara sistematis menjadi kategori sentimen positif dan negatif.
* **Model Evaluation:** Pengukuran performa model klasifikasi menggunakan matriks evaluasi (*Accuracy, Precision, Recall*).
* **Web Integration:** Antarmuka berbasis Flask untuk visualisasi ringkas dan manajemen data.

## 🛠️ Tech Stack
* **Language:** Python 3.x
* **Framework:** Flask
* **Data Analysis:** Pandas, NumPy
* **Database:** SQLite / MySQL
